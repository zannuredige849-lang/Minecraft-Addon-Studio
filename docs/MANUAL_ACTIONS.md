# Manual actions (only you can do these)

| Action | Why it is yours | When |
|---|---|---|
| Accept the Minecraft EULA and any store or subscription terms | Legal acceptance on your behalf is not allowed | Before installing or purchasing anything |
| Install Minecraft Bedrock on the iPhone | App store account | Before testing |
| Approve the project MCP server when Claude Code asks | Trust decision for a new server | First session after `.mcp.json` is added |
| Review and merge pull requests on GitHub | Keeps `main` under your control | After each feature |
| Set repository permissions or branch protection on GitHub | GitHub settings are not changed by the studio | Optional, recommended |
| Test the `.mcaddon` in Minecraft and report what you see | Only you have the game | After each build |
| Confirm `min_engine_version` for your Minecraft version | The studio marks it unverified | Before sharing |
