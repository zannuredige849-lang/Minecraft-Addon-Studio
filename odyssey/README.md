# The Odyssey (2026): Minecraft Bedrock adventure map, v3.0.0

- `world/`: the playable world (behavior pack, resource pack, LevelDB, level.dat)
- `docs/FILM_REFERENCE.md`: what the film confirms vs. what the map interprets
- `docs/CAMPAIGN.md`: the nine chapters (context, start, scenes, objectives, unlock conditions)
- `docs/START_POSITIONS.md`: every coordinate, verified against the world data
- `docs/ASSETS.md`: repaired, added and missing assets
- `docs/TEST_REPORT.md`: what was tested (and what was not)
- `docs/INSTALL.md`: install, play, build, test
- `tools/`: texture painters, lang generator, world probe, asset audit, mock-runtime tests

The baseline v2.2.0 world is the first commit that adds `odyssey/` to this repository (git history is the backup).
