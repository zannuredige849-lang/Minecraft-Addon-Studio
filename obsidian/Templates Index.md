# Templates Index

Insert with the core **Templates** plugin: command palette → **Templates: Insert template**.
The templates folder is set to `Templates`.

| Template | Use for |
|----------|---------|
| Template - Creature | regular mobs |
| Template - Boss | bosses |
| Template - Item | items and blocks |
| Template - Model | geometry files |
| Template - Animation | animations and controllers |
| Template - Script | JavaScript files |
| Template - Task | a task with its own note |
| Template - Decision | an ADR |

Templates use `{{title}}` and `{{date}}`, filled in by Obsidian.
