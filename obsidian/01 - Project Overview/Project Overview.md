# Project Overview

**Minecraft-Addon-Studio** builds add-ons for **Minecraft: Bedrock Edition**.
The repository holds the packs and this documentation vault.

## What exists today
- One behavior pack and one resource pack, linked by a manifest dependency.
- One custom entity: [[Pixel Slime]] (`studio:pixel_slime`), a small hostile slime-like mob.

## What does not exist yet
JavaScript scripts, animations, animation controllers, items, blocks, structures, bosses and factions.
These sections are ready in the vault for when work starts. See [[Tasks and Roadmap]].
