# Naming Conventions

## Add-on
- Namespace: `studio`. Identifiers: `studio:<snake_case>`, for example `studio:pixel_slime`.
- File names: `snake_case`, matching the identifier name (`pixel_slime.json`, `pixel_slime.entity.json`, `pixel_slime.geo.json`).
- Geometry: `geometry.<name>`.

## Vault
- Section folders: `NN - Title`.
- Each folder's index note has the section name, for example `Entities.md`.
- Feature notes use the display name (`Pixel Slime.md`). Supporting notes add the part (`Pixel Slime Model.md`).
- Decisions: `ADR-NNN Short Title.md`.
- Note names must be unique across the vault.
