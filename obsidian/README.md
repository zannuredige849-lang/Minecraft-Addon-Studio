# Obsidian Vault: Minecraft-Addon-Studio

This folder is an [Obsidian](https://obsidian.md) vault: the studio's knowledge base for the Bedrock add-on in this repository.

- **Open it:** in Obsidian choose *Open folder as vault* and pick this `obsidian/` folder.
- **Start note:** `Home.md`.
- **Plugins:** none required. Templates use the core *Templates* plugin, already enabled in `.obsidian/`.
- **Sync:** through this GitHub repository. See `04 - Technical Documentation/GitHub Sync Guide.md`.

Links are Obsidian wikilinks (`[[Note]]`). They work in Obsidian; GitHub's web view shows them as plain text.

Device-specific Obsidian files (`workspace*.json`, cache, plugin settings) are git-ignored so phone and computer do not fight over them.
