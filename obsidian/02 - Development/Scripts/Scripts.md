# Scripts

Status: **none yet**. There is no `BP/scripts/` folder and no `script` module in the behavior pack manifest.

## When adding the first script
- Add a `script` module (`"type": "script"`, `"language": "javascript"`, `"entry": "scripts/main.js"`) to `BP/manifest.json`.
- Add a dependency on `@minecraft/server` with a version that matches the target game version.
- Update [[Pack Manifests]] and [[Dependencies and Requirements]].
- Use **Template - Script** for the note.
