# Animations

Status: **none yet**. The repository has no `RP/animations/` or `RP/animation_controllers/` folder.

The [[Pixel Slime]] has no custom animation. Its client entity defines no `animations` or `scripts.animate` block.

## When adding the first one
- Animations go in `RP/animations/<name>.animation.json`, controllers in `RP/animation_controllers/`.
- Reference them from the client entity's `animations` map and `scripts.animate`.
- Use **Template - Animation** for the note.
